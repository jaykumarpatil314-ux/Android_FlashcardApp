# CodeAlpha_Android_FlashcardApp

A Native **Android Mobile Application** developed in **Java** for the **CodeAlpha Mobile & Web Application Development Internship (Task 1)**, connected with the **Java REST Backend**.

![Android](https://img.shields.io/badge/Platform-Android%20%7C%20Java-3DDC84?style=for-the-badge&logo=android)
![Backend](https://img.shields.io/badge/Backend-Java%20HTTP%20REST-orange?style=for-the-badge&logo=openjdk)

---

## 🌟 Mobile Features

- 📱 **Interactive 3D Card Flip**: Built with Android 3D property animations (`rotationY`).
- 🔄 **"Show Answer" & "Back to Question" Buttons**: Smooth card flipping between front and back.
- ⏩ **Next & Previous Navigation**: Easily browse through flashcard decks with automatic progress tracking.
- ➕ **Add Custom Flashcards**: Native Android AlertDialog with text inputs for Question, Answer, and Category.
- 🌐 **Java Backend Synchronization**: Syncs with the `CodeAlpha_Java_Backend` running on port 8080 (`http://10.0.2.2:8080/api/flashcards`) with seamless offline fallback!

---

## 🚀 How to Run in Android Studio

1. Open **Android Studio**.
2. Select **File > Open...** and choose this folder: `CodeAlpha_Android_FlashcardApp`.
3. Wait for Gradle sync to complete.
4. Select an Android Emulator or connect a physical Android device via USB debugging.
5. Click **Run (Shift + F10)** to launch the app!
